# ALEX-NET
# AlexNet Image Classification

This project implements an **AlexNet-based Deep Learning model** for image classification using the **CIFAR-10 dataset**. The dataset contains 60,000 RGB images of size 32×32 pixels belonging to 10 different classes: Airplane, Automobile, Bird, Cat, Deer, Dog, Frog, Horse, Ship, and Truck. The model uses convolutional layers, max-pooling, fully connected layers, dropout, and softmax for classification. It is trained and evaluated using **TensorFlow/Keras**, with accuracy and loss graphs used to analyze the model performance. The project also supports uploading a new image and predicting its class along with the confidence score.
